# NUCLEO-L552ZE-Q source pack

This directory contains the [UM2581 reference manual](docs/um2581-stm32l5-nucleo144-board-mb1361-stmicroelectronics.pdf),
Rev 5, May 2022, previously filed under the STM32L5 family. The manual identifies
the NUCLEO-L552ZE-Q product and MB1361 reference board. Those identities justify
the product directory; no physical-board revision is inferred from the manual
revision.

The PDF moved unchanged. No platform manifest, reconciled silicon/register map,
pin inventory, startup path or accepted executable is present. These remain
source materials for future support.
