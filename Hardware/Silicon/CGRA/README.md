# CGRA Scaffolding

This folder reserves canonical substrate space for future CGRA platform packages.

Recommended leaf shape mirrors other substrates:

- `Hardware/Silicon/CGRA/<Vendor>/<Family>/<Device>/Fidelity.Platform.fidproj`
- Typed platform declaration sources listed in that manifest

No CGRA leaf package is defined yet.

[CGRA integration requirements](INTEGRATION.md) records the compiler, runtime,
memory and validation artifacts needed for a real package, using Maverick-2 as
a researched example. ELF support alone does not establish a backend.
